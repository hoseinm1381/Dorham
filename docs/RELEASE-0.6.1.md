# Dorham 0.6.1 - voice-channel games

Games now sits beside Share screen in the connected voice controls. The catalog currently offers Chess; users choose settings and create a game without selecting a person. The active voice channel gains a Join [host]'s game row. Opening it watches first, and Play claims the open second seat. Standard/Elixer, all clock choices and Easy/Medium/Hard AI remain available; Expert remains disabled.

Seat assignment and clock start commit atomically. Stale or competing claims refresh the board and keep the late claimant watching. Lost creation responses recover the existing game. Room changes, disconnects, reconnects, host departure and expiry have explicit recovery paths. Closing the game leaves voice connected. Legacy 0.6.0 matches remain resumable. See [behavior, rules and architecture](CHESS.md).

The catalog, small channel directory and Games button use the current app/socket. The larger chess screen and artwork remain lazy and excluded from eager PWA caching. Normal moves do not refetch the directory; idle games do not poll. No dependency, engine, hosting or media-budget changes are introduced. Schema 7 adds a nullable channel binding and index while preserving old game state.

Windows remains unsigned; Android and previous large-call capacity limits remain deferred. Physical acoustics are not measured by synthetic media checks.

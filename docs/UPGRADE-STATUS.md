## Verification and measurements

`npm run verify`: lint, TypeScript, **35 unit/integration tests**, API/web/desktop production builds pass. Five expansion browser scenarios pass in one guarded run. Existing account/chat/DM/PWA, microphone controls, decoded mesh/speech/screen regressions pass separately. Public API/WSS/polling/replay, adversarial cached-token admission, Chrome SFU, Windows SFU and forced TURN/TLS scenarios pass. Fresh dependency review reports zero npm advisories. Native APK outputs and Windows installer are versioned; no new runtime dependency was added.

The 20-socket local Windows workload measured p50 124.41 ms, p95 **183.99 ms**, maximum 186.08 ms acknowledgements; peak RSS **405.46 MiB**, final RSS **365.45 MiB**, mean 92.72% of one core over 5.75 seconds, event-loop p95 120.98 ms, database/WAL 4,791,997 bytes. Peak remains below 640 MiB and final below the initial 384 MiB target. Registration/hash work is included; these are not sustained VPS/SFU capacity measurements. A post-restart hosted Node cgroup sample was about 46 MiB before representative traffic.

Browser budget remains 4 GiB combined. Earlier attempts stopped at the guard and are not accepted as completed tests. The final five-case expansion run peaked at **2,200.2 MiB combined**; installed Windows/Chrome media peaked at **2,713.5 MiB combined**. Only test-owned processes are stopped. Never run the 16/20-browser media capacity scenario on this workstation.

Evidence is retained locally under `artifacts/evidence/expansion-*`, `ninecraft-sfu-*.json/png`, `control-plane-load.json`, and `artifacts/logs/expansion-*`. Credentials, conversations, backup exports and signing files remain outside Git. A default runtime npm install attempted an unnecessary SQLite native rebuild on this machine and failed for missing Windows SDK; the pinned package includes prebuilt addons. The independent runtime install passed using `npm ci --omit=dev --ignore-scripts`, followed by actual SQLite, Argon2, HTTP and WebSocket smoke checks. Linux deployment reused the matching previously verified Linux-native dependencies; no Windows modules were copied.

# Dorham 1.0.6 — Windows overlay refinement

The Windows voice overlay has no panel background, border or channel header. Only circular profile pictures (initials when unavailable), names and microphone/headphone icons remain. Names and icons remain fully opaque, with a small shadow for contrast. Profile pictures are downscaled to bounded 64-pixel PNG thumbnails in the main application; the isolated overlay accepts only size-limited PNG data URLs and cannot fetch remote images. Every participant has a microphone and headphone icon: a crossed-out microphone indicates mute/server mute/deafen, and crossed-out headphones indicate deafen. Speaking keeps the green highlight. Status labels remain available to accessibility tools in English and Persian.

Overlay controls now live in Settings → Game overlay, visible only in Windows clients with the native overlay bridge. The enable switch and four corner positions stay together. Existing overlay preferences and the off-by-default behavior are preserved.

This is a Windows-only patch using the existing Electron shell. The operator deferred Tauri. The louder mute/unmute cues from 1.0.5 remain included. Public web stays 1.0.5, Android stays the original signed 1.0.4, and the running API/data schema stay 1.0.4. No server restart or Caddy change is needed. The existing app ID and NSIS identity are preserved so installation upgrades the same app. Windows remains unsigned as previously authorized.

The 1.0.5 overlay was confirmed visible and working in Age of Empires IV by the operator. The 1.0.6 visual change requires operator acceptance in-game; exclusive fullscreen remains unsupported. Verification and publication results are recorded in artifacts/v1.0.6/release.json and its Verification ZIP.

Local verification passes lint, types, web/desktop builds and six focused overlay/release-contract tests. All 124 packaged web files and 11 shell/overlay files match their build inputs. The actual installed-app test verifies a real uploaded profile picture, real voice mute/deafen changes, all status-icon combinations, zero background opacity, English/Persian layout, settings placement/persistence, four-corner geometry, sandbox boundaries, lock/leave hiding, and Win32 click-through/no-focus flags with a real mouse click into an underlying borderless test window. The real isolated 1.0.5-to-1.0.6 installer upgrade keeps the same directory/GUID and one uninstall entry; the personal application files, registry and shortcuts are preserved/restored.
